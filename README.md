# Chinese Micron Turtorial (中译版Micron教程)

**Micron** is a simple and practical markup language used in *Nomad Network*. This basic tutorial on Micron is based on the Micron Markup source text of the micron-parser-js project and translated into Chinese by Inter-Asiree.

**Micron**是用于*Nomad Network*的一种简单且实用的标记语言，该Micron基础教程基于micron-parser-js工程的Micron Markup原文，由Inter-Asiree翻译为中文。

The Chinese translation of the Micron tutorial is available in the [CMicronTurtorial.mu file](CMicronTurtorial.mu)

Micron教程中译版在 [CMicronTurtorial.mu文件](CMicronTurtorial.mu) 中
